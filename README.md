# RN Paper App

Projeto desenvolvido para a disciplina de **Programação de Software e Aplicativo II**.

## Funcionalidades

- **Home:** utilização de componentes do React Native Paper.
- **Cadastro e Login:** autenticação de usuários com Firebase Authentication.
- **Firestore:** armazenamento dos dados dos usuários, incluindo nome, e-mail, telefone e endereço.
- **Perfil:** consulta e exibição dos dados do usuário autenticado.
- **Navegação:** React Navigation com Stack e Drawer Navigator.

## Tecnologias

- React Native e Expo
- React Native Paper
- React Navigation
- Firebase Authentication
- Cloud Firestore
- Redux

## Como executar

```bash
npm install
npx expo start
```

**Configuração:** é necessário configurar as credenciais do Firebase, ativar o Authentication e criar um banco Cloud Firestore.
